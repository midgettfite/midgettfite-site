# MF-311 — Invite the office to the listings editor

**Kind:** story · **Status:** DRAFT · **Source:** `docs/MF-Website-Migration-Plan.md` §4, §6 B2
**Related:** office training (MF-314), go-live (MF-312)
**Part of:** Website

**As** office staff,
**I want** to sign in to the listings editor with my email,
**so that** I can add, change and remove listings myself, without a GitHub account and without calling Steve.

## Background
The editor is Pages CMS (free). Staff are invited by email and sign in with a one-time link: **no GitHub
account, no password.** Their changes are saved to M&F's repo and the site republishes in about a minute.
It is already connected to M&F's repo (MF-309); only the invitations are left. They were held back on
purpose so staff aren't handed an editor before they're shown how to use it.

## Acceptance criteria
1. Each person Dan names receives an invitation at their Zoho address and signs in with the emailed link.
2. Each sees the listings form and nothing else.
3. Each person's first change happens during training (MF-314), on a test listing, and is deleted afterwards.
4. Removing someone's access is written down in one line, for when staff change.
